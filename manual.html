อสม. ควรรู้สัญญาณที่อาจเกี่ยวข้องกับปัญหาสุขภาพจิต เพื่อช่วยคัดกรองและส่งต่อเร็วขึ้น

อาการที่ควรสังเกต

  • เศร้า เบื่อ ไม่อยากทำอะไร
  • นอนไม่หลับหรือหลับมากผิดปกติ
  • กินน้อยลงหรือกินมากขึ้นมาก
  • เครียด กังวล หงุดหงิดง่าย
  • แยกตัว ไม่เข้าสังคม
  • ใช้สุรา/สารเสพติดเพิ่มขึ้น

คำเตือน

อาการเหล่านี้เป็นเพียงสัญญาณที่ควรดูแลต่อ ไม่ใช่ข้อสรุปการวินิจฉัย ให้ใช้แบบคัดกรองและส่งต่อเมื่อจำเป็น

  1. เปิด LINE Rich Menu แล้วกด แบบคัดกรองสุขภาพจิต
  2. ระบบจะตรวจ LINE ID อัตโนมัติ ถ้ายังไม่ผูกให้กรอก Username/Password
  3. ตรวจชื่อผู้ใช้งานด้านบนก่อนเริ่มคัดกรอง
  4. ถ้าเข้าไม่ได้ ให้ตรวจตัวสะกดหรือใช้เมนูลืมรหัสผ่านด้วยรหัสลับ
  1. กรอกข้อมูลทั่วไปให้ครบก่อนถาม
  2. ถามตามข้อความในระบบ ไม่ปรับคำถามจนความหมายเปลี่ยน
  3. ไม่ชี้นำคำตอบ เช่น ไม่พูดว่า “ตอบไม่มีใช่ไหม”
  4. ถ้าระบบพบความเสี่ยง จะเปิด 9Q ต่อโดยอัตโนมัติ
  5. ตรวจสรุปก่อนกดส่งทุกครั้ง
  1. ถามให้ครบทุกข้อและเลือกคะแนนตามคำตอบจริง
  2. อย่าแปลผลเกินบทบาท ให้ใช้ผลเพื่อส่งต่อ/ติดตาม
  3. ถ้าระบบขึ้นให้ทำ 8Q ต่อ ให้ทำตามขั้นตอนทันที
  4. หากผู้รับการประเมินไม่สบายใจ ให้หยุดพักและรับฟังอย่างสงบ
สำคัญ: ถ้ามีความเสี่ยงต่อชีวิตหรือความปลอดภัย อย่าปล่อยให้อยู่ลำพัง และให้ติดต่อเจ้าหน้าที่/ญาติ/หน่วยฉุกเฉินในพื้นที่ทันที
  1. ถามด้วยน้ำเสียงสงบ ไม่ตำหนิ ไม่ตัดสิน
  2. กรอก 8Q ตามคำตอบจริง
  3. กดส่งข้อมูลเพื่อให้ระบบแจ้งเตือนเจ้าหน้าที่
  4. หากเป็นเหตุเฉพาะหน้า ใช้ช่องทางฉุกเฉินของพื้นที่ทันที
  1. ใช้เมื่อเหมาะสมเพื่อประเมินความเครียดเพิ่มเติม
  2. ถ้าไม่ได้ประเมิน ระบบจะบันทึกว่าไม่ได้ประเมิน ไม่ถือว่าผิด
  3. ถ้าพบความเครียดสูง ให้พิจารณาแจ้งเจ้าหน้าที่ตามบริบทพื้นที่

ควรพูด

“เล่าให้ฟังได้นะครับ/คะ ถ้าสะดวก”
“ข้อมูลนี้จะใช้เพื่อช่วยดูแลและส่งต่อให้เหมาะสม”
“ช่วงนี้รู้สึกเหนื่อยหรือเครียดมากขึ้นไหมครับ/คะ”

ควรหลีกเลี่ยง

  • “คิดมากไปเอง”
  • “คนอื่นหนักกว่านี้ยังทนได้”
  • “อย่าทำให้ครอบครัวเสียใจ”
  • “ตอบว่าไม่มีเถอะ จะได้จบเร็ว”
  • พูดว่าไม่อยากมีชีวิตอยู่ หรืออยากหายไป
  • มีแผนหรือเตรียมวิธีทำร้ายตนเอง
  • เคยพยายามทำร้ายตนเอง
  • อยู่ลำพังและมีความเสี่ยง
  • เมาสุรา/ใช้สารเสพติดร่วมกับอารมณ์รุนแรง
  • มีพฤติกรรมก้าวร้าว ควบคุมตนเองไม่ได้ หรือมีอุปกรณ์เสี่ยงใกล้ตัว
เสี่ยงต่ำ→แนะนำ/ติดตาม→เสี่ยงปานกลาง→แจ้งเจ้าหน้าที่→เสี่ยงสูง→เร่งส่งต่อ
  1. บันทึกข้อมูลให้ครบก่อนส่ง หากสถานการณ์ปลอดภัย
  2. แจ้งเจ้าหน้าที่ รพ.สต./Admin/Hospital ตามระบบ
  3. ถ้ามีความเสี่ยงเฉพาะหน้า ให้ใช้ช่องทางฉุกเฉินของพื้นที่ทันที
  4. ติดตามผลตามที่เจ้าหน้าที่มอบหมาย ไม่รับภาระคนเดียว

จำง่าย: รู้เท่าที่จำเป็น ใช้เพื่อช่วยเหลือ ไม่เผยแพร่ต่อ

  • แจ้งวัตถุประสงค์ก่อนเก็บข้อมูล
  • ไม่ส่งชื่อ/ผลคัดกรองในกลุ่มที่ไม่เกี่ยวข้อง
  • ไม่พูดต่อในชุมชน
  • ใช้ข้อมูลเพื่อดูแลและส่งต่อเท่านั้น
  • เปิดข้อมูลเฉพาะเจ้าหน้าที่ที่เกี่ยวข้องกับการดูแล
  1. อย่าปิดหน้าเว็บทันที ให้ดูว่ามี draft หรือข้อความแจ้งเตือนหรือไม่
  2. เมื่ออินเทอร์เน็ตกลับมา ให้กดส่งซ้ำตามคำแนะนำของระบบ
  3. ถ้าส่งซ้ำแล้วยังไม่ได้ ให้จดชื่อผู้รับการประเมินและแจ้งเจ้าหน้าที่
  4. หากเป็นเคสเสี่ยงสูง ให้แจ้งเจ้าหน้าที่ทันที ไม่รอให้ระบบส่งสำเร็จ
  • รู้ว่าตนเองเป็นผู้ช่วยคัดกรองและประสานงาน ไม่ใช่ผู้รักษาหลัก
  • เมื่อเจอเคสหนัก ให้แจ้งเจ้าหน้าที่ ไม่เก็บไว้คนเดียว
  • หลังรับฟังเรื่องเครียดมาก ควรพักและพูดคุยกับทีม
  • ถ้าเริ่มรู้สึกเครียด/นอนไม่หลับ/กังวลจากงาน ให้ขอคำปรึกษา
